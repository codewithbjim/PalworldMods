Version 0.2.0-rc.1 - Event-driven gamepad integration and callback-lifecycle hardening

Added
- Add native gamepad placement controls and matching controller prompts to the companion key guide.
- Use L3 to freeze or unfreeze, L3 plus D-pad Down to copy a targeted piece, and L3 plus D-pad Up to copy its transform and freeze the replacement preview.
- Move with the D-pad, use LT plus the D-pad for height and movement-step changes, rotate with LB or RB, and reset with R3 while frozen.
- Add optional DarnMenu settings for gamepad enablement, direction inversion, and rotation-button swapping.

Fixed
- Route keyboard, mouse, and gamepad actions through the same transition-aware game-thread dispatcher so stale input is discarded during freeze, unfreeze, and piece-switch transitions.
- Retain the gamepad Blueprint callback and both returned UE4SS hook IDs so callback garbage collection cannot silently remove controller input.
- Prevent the known UE4SS EngineTick callback-reference failure path by replacing per-action callback churn with stable, owned game-thread actions.
- Coalesce rapid keyboard input and frozen-validity refreshes through reusable game-thread callbacks instead of registering a new callback for every action.
- Reuse one owned, cancellable game-thread loop while Copy and Freeze waits for the replacement preview to become ready.
- Hide the companion Placement Controls guide when Palworld destroys its construction widget without touching stock widget rows during teardown.

Performance
- Dispatch controller actions only when the Blueprint reports a physical chord, with no recurring Lua gamepad polling.
- Keep immediate and delayed game-thread scheduling in a dedicated runtime helper that prefers EngineTick and owned delayed actions.
- Remove the frozen preview's 10 Hz lifecycle watchdog; Palworld construction events now drive release and guide visibility without recurring UObject polling.

Testing
- Add Lua 5.4 scheduler stress tests for callback identity, 10,000-input bursts, throttling, cancellation recovery, failure isolation, and bounded FIFO fallback behavior.

Version 0.1.7-rc.3 - Input, guide, and performance hotfix

Added
- Copy and Freeze to Targeted Piece is now shown in the bundled control guide. Ctrl+Shift+Middle Mouse copies the targeted piece, transfers its position and rotation, and freezes the replacement preview there.

Fixed
- Prevent rapid movement, rotation, or Reset input from breaking the game-thread dispatcher and leaving every placement control unresponsive.
- Use EngineTick for immediate placement work and prefer owned delayed game-thread actions while retaining callbacks until completion.
- Correct construction Blueprint hook registration and keep each callback and both returned hook IDs alive.
- Hide the Placement Controls guide on the title screen and whenever no live construction preview exists.
- Restore the unfrozen guide for a live preview, then hide or release it on Escape, build-menu changes, destruction, and construction UI closure.

Performance
- Remove recurring guide and lifecycle polling during normal gameplay and unfrozen building, eliminating the roughly twice-per-second idle polling path associated with rhythmic microstutter.

Changed
- Live red/blue frozen-validity feedback now defaults to On and can be disabled in DarnMenu if collision and material refresh causes input-linked stutter.
- All DarnMenu changes apply after restarting Palworld.

Version 0.1.7-rc - Stability and validity feedback

Fixed

Previous 0.1.2 notes

Features
- Freeze and release a live construction preview while walking around it.
- Move frozen previews horizontally or vertically in configurable centimeter increments.
- Allow vertical adjustment from 25 cm below to 650 cm above the frozen origin.
- Update the in-game keyboard guide with the Numpad 3/1 vertical controls.
- Rotate around the captured build-piece pivot.
- Reset to the transform captured when the preview was frozen.
- Copy the targeted build piece into the active preview.
- Package the Lua and Logic Mod components through Palworld's official Workshop loader.

Performance and reliability
- Cache the local player's BuilderComponent instead of rediscovering it every 500 ms outside build mode.
- Prefer direct player lookups before falling back to a global PalPlayerCharacter scan.
- Run frozen-preview safety checks on the game thread at 10 Hz and idle guide checks at 2 Hz.
- Back off failed global player scans for approximately five seconds.
- Disable verbose diagnostics by default.
- Keep the unfinished gamepad guide hidden.
- Ignore middle-mouse bindings unless a live construction preview is active.
- Resolve the active preview directly from the local BuilderComponent, avoiding the global preview scan and stutter when middle mouse is used in normal play.
- Remove the legacy Alt+F6, Alt+F7, Alt+F8, Ctrl+Middle Mouse, and Alt+Middle Mouse bindings.

Known limitations
- This is an experimental beta; test it in a disposable world or backed-up save.
- Final confirmation/cancel integration with Palworld's authoritative placement path is incomplete.
- The companion key-guide UI is not reliable on every current setup.
- Gamepad controls are disabled.
- Dedicated-server and non-host multiplayer behavior is unverified.
