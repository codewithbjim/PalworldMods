Version 0.1.7-rc.2 - Freeze lifecycle hotfix

Fixed
- Prevent a successfully frozen preview from immediately auto-releasing while Palworld rebuilds the construction key guide.
- Pause lifecycle release checks while Freeze or Unfreeze is settling.
- Keep automatic guide cleanup after leaving construction without trusting an initially hidden or stale widget.

Changed
- Live red/blue frozen-validity feedback is now optional and disabled by default because its collision and material refresh can cause visible stutter.
- Enable the experimental option in DarnMenu only if live validity feedback is worth the performance cost.

Version 0.1.7-rc.1 - Optional DarnMenu integration

Changed
- DarnMenu is now optional instead of a required Workshop dependency.
- Without DarnMenu, Perfect Placement uses its built-in controls and Scripts/config.lua defaults unless a saved player override already exists.
- Install DarnMenu 1.6.2 or newer only for in-game Mod Options and saved player overrides.
- Correct the package dependency identifier for the official UE4SS Experimental item.

Version 0.1.7-rc - Stability and validity feedback

Fixed
- Refresh valid/invalid placement feedback after frozen movement, rotation, and Reset.
- Verify transforms after UE4SS FHitResult output-marshalling errors so the checker and visible preview remain synchronized.
- Harden callback lifetimes to prevent controls and the frozen UI becoming unresponsive after rapid input.
- Harden build-piece switching against stale or spammed transitions.
- Reacquire delayed UI objects safely after map and widget changes.

Performance
- Stop scanning every construction widget during normal lifecycle polling.
- Scan once for each new active preview, then reuse the cached live widget.
- Coalesce pending game-thread work during hitches and rapid input.

Compatibility
- Prefer UE4SS's isolated ProcessEvent route when available, with the existing queue as fallback.
- DarnMenu 1.6.2 or newer remains required.

Version 0.1.6-release - Configuration and lifecycle stability

Added
- Configure Perfect Placement under ESC > Mod Options > Perfect Placement with DarnMenu 1.6.2.
- Remap every placement action with native key-chord controls.
- Configure movement increments, step limits, vertical bounds, and verbose diagnostic logging in game.
- Save player overrides in Mods/shared/PerfectPlacement_user.lua.

Fixed
- Prevent placement UI recreation and world reloads from registering duplicate input callbacks.
- Keep each keypress limited to one placement action.
- Hide the placement guide when construction mode closes.
- Refresh displayed keycaps safely when the placement UI is recreated.

Changed
- Replaces Mod Config Menu and removes its obsolete schema and reader.
- Requires DarnMenu 1.6.2 or newer. DarnUI is installed through DarnMenu.
- Uses Scripts/config.lua defaults when no saved player override is available.
- Applies binding and configuration changes after restarting Palworld.

Previous 0.1.2 notes

Features
- Freeze and release a live construction preview while walking around it.
- Move frozen previews horizontally or vertically in configurable centimeter increments.
- Allow vertical adjustment from 25 cm below to 650 cm above the frozen origin.
- Update the in-game keyboard guide with the Numpad 3/1 vertical controls.
- Rotate around the captured build-piece pivot.
- Reset to the transform captured when the preview was frozen.
- Copy the targeted build piece into the active preview.
- Package the Lua and Logic Mod components through Palworld's official Workshop loader.

Performance and reliability
- Cache the local player's BuilderComponent instead of rediscovering it every 500 ms outside build mode.
- Prefer direct player lookups before falling back to a global PalPlayerCharacter scan.
- Run frozen-preview safety checks on the game thread at 10 Hz and idle guide checks at 2 Hz.
- Back off failed global player scans for approximately five seconds.
- Disable verbose diagnostics by default.
- Keep the unfinished gamepad guide hidden.
- Ignore middle-mouse bindings unless a live construction preview is active.
- Resolve the active preview directly from the local BuilderComponent, avoiding the global preview scan and stutter when middle mouse is used in normal play.
- Remove the legacy Alt+F6, Alt+F7, Alt+F8, Ctrl+Middle Mouse, and Alt+Middle Mouse bindings.

Known limitations
- This is an experimental beta; test it in a disposable world or backed-up save.
- Final confirmation/cancel integration with Palworld's authoritative placement path is incomplete.
- The companion key-guide UI is not reliable on every current setup.
- Gamepad controls are disabled.
- Dedicated-server and non-host multiplayer behavior is unverified.
