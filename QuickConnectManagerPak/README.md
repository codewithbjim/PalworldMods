# Quick Connect UI pak

This package contains the cooked `WBP_QuickConnectPanel` widget at `/Game/Mods/QuickConnectManager/`. The widget is a uniquely named clone of Palworld's common-window shell, so disclaimer-suppression mods do not identify or hide it.

Run `build.ps1` to create `Dist/QuickConnectManager_UI_P.pak` with the repository's cooked widget pair and `F:\Hobby Project\Palworld Tools\UnrealPak.exe`.
